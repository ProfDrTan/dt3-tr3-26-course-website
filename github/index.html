Never used GitHub before? Start here.

You don't need to install anything or use a command line for what this course needs. Everything below can be done directly in your browser.

The fastest way to make your first commit — no software needed
  1. Open your team's repo (the link from your invite email).
  2. Click on any file — for example, README.md.
  3. Click the pencil icon (top right of the file view) to edit it directly in the browser.
  4. Make your change, then scroll down — you'll see a box asking you to describe what you changed.
  5. Click "Commit changes". That's it — you've just made your first commit.
Quick vocabulary — the only four words you actually need
  • Repository (repo) — your team's shared folder, where all files live.
  • Commit — a saved snapshot of a change, with a short note describing it.
  • README — the file that shows automatically when you open a repo, usually an overview.
  • Organization (org) — the shared account (cp3405-tr3-2026) that owns every team's repo.
If you want a proper walkthrough — video and written guides
  • GitHub's own official beginner guide — written, covers repos, commits, and pull requests from zero.
  • GitHub Tutorial for Beginners (video) — uses GitHub Desktop, a visual app rather than the command line, good if you'd rather see it done than read it.
