New: Your Gold Technical Engine

Open the Investing.com page above. For each timeframe it shows one rating, from Strong Sell to Strong Buy, worked out from a table of moving averages and a table of indicators, each voting Buy or Sell. It also shows pivot points. You will build the same thing for gold futures, December 2026 (Yahoo symbol GCZ26.CMX), on three timeframes: hourly, daily and weekly. Those are tabs on the Investing.com page too.

Start from the starter kit: sprint6-starter.zip. Put its contents in an engine/ folder in your repo. The download and file handling are written for you. You write the 14 functions marked TODO: the maths and the voting rules, each explained in the file. Then run python engine/test_engine.py. It checks your numbers and votes against the course reference engine on frozen gold data, and tells you exactly which line is wrong. Commit its output to checks/engine-test.txt.

The 12 moving-average votes

For each length n = 5, 10, 20, 50, 100 and 200 bars, a simple moving average (SMA, the plain average of the last n closes) and an exponential moving average (EMA, which gives recent closes more weight). Each votes Buy if the latest close is above it and Sell if below. These are the same 12 rows as Investing.com's Moving Averages table.

Votes, rating, prediction and pivots

Score: S = (B − D) ÷ 18
where B is the number of Buy votes, D the number of Sell votes, and 18 the total. S runs from −1 (all Sell) to +1 (all Buy).

Rating: S of 0.5 or more is Strong Buy · 0.1 up to 0.5 is Buy · between −0.1 and 0.1 is Neutral · −0.5 up to −0.1 is Sell · −0.5 or less is Strong Sell.

Predicted next close: P = C + 0.1 × S × ATR
where C is the latest close, S the score, and ATR (average true range) the typical size of one bar's move over the last 14 bars. A Strong Buy predicts a small rise, Neutral predicts no change. The 0.1 was set by testing: a larger step overshoots.

Pivot points: P = (H + L + C) ÷ 3 · R1 = 2P − L · S1 = 2P − H
where H, L and C are the high, low and close of the last completed bar on that timeframe. P is the pivot, R1 the first resistance above it and S1 the first support below it.

Comparing with Investing.com

Your engine writes signals/latest.json, with the time of the bar it used in UTC (the same as GMT, which Investing.com uses). Compare at the same bar time and on the same timeframe tab. Your moving averages should agree with Investing.com's to within about 0.2%. Indicators can differ a little more, because Investing.com's price feed can differ from Yahoo's by a few dollars and fast indicators react to that. The summary rating may differ, because Investing.com counts more indicators than these six. Be ready to explain any difference, row by row.

New: The Replay (R4)

Run your engine as if it were running at each of the last 35 hourly bars, the last 20 daily bars and the last 10 weekly bars, using only the bars up to that point. Compare each prediction with the close that actually came next. Save every row in replay/vW6.csv (bar time, timeframe, close, score, rating, predicted, actual, miss, no-change miss) and a summary for each timeframe in replay/vW6.json.

Miss = |P − A| ÷ A × 100
where P is the predicted close, A the actual close, and |…| the size of the miss, whether above or below.

"No change" miss: the same formula with P = C, the last close. This is the simplest possible forecast. Report both: an engine that can't beat "no change" isn't adding anything, and you should say so.

Direction right: the share of Buy and Strong Buy ratings followed by a higher close, plus Sell and Strong Sell ratings followed by a lower close, out of all non-Neutral ratings.
