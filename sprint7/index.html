Build Investing.com’s gold technical page yourselves, including the 1, 5 and 15-minute views that Investing.com locks behind a subscription.

Correction (20 Oct): build the gold page as ui/gold.html. Do not overwrite ui/index.html: it stays your team dashboard (roles, commit history, FigJam) and must link to gold.html.
This sprint has one deliverable: ui/gold.html, a working copy of Investing.com’s gold technical page. Same layout, same three gauges, same tables, for seven timeframes. Every number on it must show how it was calculated. It is a study week, so nothing else new is asked of you: lock your weekly calls as in Sprint 6, and spend the rest of the week on this page.
Why this sprint exists. In Sprint 6, dashboards were not shown, numbers could not be checked against Investing.com, and the formulas behind them could not be found. This sprint fixes that. If it cannot be checked during your presentation, it scores zero. The five rules below are pass or fail.

4. The 12 indicators and their rules

Your first task (R3) is to open Technical Indicators › on Investing.com, compare its list and settings with this table, and record any difference in docs/verify.md. Where Investing.com differs, follow Investing.com and note it.

IndicatorCalculationAction
RSI(14)Wilder’s 14-bar average gain and loss. RSI = 100 − 100/(1 + avg gain/avg loss)Buy > 50, Sell < 50, Neutral above 70 or below 30
STOCH(9,6)%K = (close − 9-bar low)/(9-bar high − 9-bar low) × 100; %D = 6-bar average of %KBuy if %K > %D and %K < 80; Sell if %K < %D and %K > 20; else Neutral
STOCHRSI(14)(RSI − lowest RSI of 14 bars)/(highest − lowest) × 100Buy > 50, Sell < 50, Neutral above 80 or below 20
MACD(12,26)EMA12 − EMA26; signal = 9-bar EMA of MACDBuy if MACD > signal, else Sell
ADX(14)Wilder’s +DI, −DI and ADX over 14 barsIf ADX > 20: Buy when +DI > −DI, Sell when −DI > +DI. Otherwise Neutral
Williams %R(14)(14-bar high − close)/(14-bar high − 14-bar low) × −100Buy > −50, Sell < −50, Neutral above −20 or below −80
CCI(14)(typical price − its 14-bar average)/(0.015 × mean deviation); typical price = (H + L + C)/3Buy > 0, Sell < 0, Neutral beyond ±200
ATR(14)Wilder’s 14-bar average of the true rangeNo vote. “High Volatility” if above its own 14-bar average, else “Less Volatility”
Highs/Lows(14)close − midpoint of the 14-bar high and lowBuy > 0, Sell < 0. Check Investing.com’s definition (R3).
Ultimate Oscillator100 × (4·A7 + 2·A14 + A28)/7, where An = sum of buying pressure ÷ sum of true range over n barsBuy > 50, Sell < 50, Neutral above 70 or below 30
ROC(12)(close ÷ close 12 bars ago − 1) × 100Buy > 0, Sell < 0
Bull/Bear Power(13)(high − EMA13) + (low − EMA13)Buy > 0, Sell < 0

Moving averages (12 votes)

For n = 5, 10, 20, 50, 100 and 200: the simple (SMA) and exponential (EMA) moving average of the close. Buy if the last close is above it, Sell if below.

Ratings (our rule, the same for every team)

score = (number of Buys − number of Sells) ÷ number of votes. Strong Buy ≥ 0.5 · Buy ≥ 0.1 · Neutral between −0.1 and 0.1 · Sell ≤ −0.1 · Strong Sell ≤ −0.5.
Technical Indicators gauge: the 11 voting indicators. Moving Averages gauge: the 12 MA votes. Summary: all 23 votes together. The needle points at the score, from −1 (far left) to +1 (far right). Write this rule on your page.

5. How to run it (and why)

The page is not hosted anywhere. It runs on your laptop.

python engine/dashboard_data.py --loop 60   # refreshes ui/data.json every 60 s
cd ui && python -m http.server 8000       # then open http://localhost:8000/gold.html
  • Open it through the local server, not by double-clicking the file. Browsers usually block a page opened as a file from reading data.json; that is the classic “it works on my machine” failure.
  • Do not use GitHub Actions’ schedule to refresh data. Its short-interval timing is unreliable; it has stalled for hours.
  • The only workflow allowed in your repo is still .github/workflows/predict.yml. No Netlify, no Pages, no public hosting.

4Everything in the repo. The page reads only from code and data committed to your repo. If it is not on main by Saturday 23:59, it does not exist.
5Live test on Monday. No slides or screenshots in place of the page (section 9).
